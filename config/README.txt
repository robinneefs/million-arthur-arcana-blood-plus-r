Arcana Blood +R  -  rollback netcode mod for Million Arthur: Arcana Blood (Steam)
===============================================================================
Version: see the bottom right of the main menu. This is a BETA: problems are expected.

You need: the Steam version of Million Arthur: Arcana Blood, Steam running,
and a controller (keyboard and mouse work in the menus).

INSTALLING
  Installer: run ArcanaBlood-PlusR-...-Setup.exe. It puts the mod in its own
  folder (%LOCALAPPDATA%\Arcana Blood +R) and makes an "Arcana Blood +R"
  shortcut on the Desktop and in the Start menu. No game file is changed.
  Zip: unzip everything into a folder of your own (not the game's folder) and
  start arcana_launcher.exe from there.
  First time: Windows may say "Windows protected your PC". Click "More info",
  then "Run anyway" (the mod is not code-signed). If your antivirus removes a
  file of the mod, restore it and allow the folder: it is a false alarm
  (please tell us on GitHub).

STARTING
  Start "Arcana Blood +R" (arcana_launcher.exe). It checks for updates, then
  Play starts the game with the mod. Steam has to be running.
  Play puts one small file into the game's folder: dinput8.dll. It does
  nothing unless the launcher started the game, so the game started from
  Steam is the plain game. (Another dinput8.dll there is kept as
  dinput8.dll.before-plusr.) Hold Shift while the game starts to play
  without the mod.

FIRST STEPS
  - Y on the main menu: My setup (character, colour, stage, Support Knights).
    Set this first, it is what you play with.
  - Settings: controls, sound, display, input delay.
  - F1 (or Back + Start) opens / closes the main menu.

PLAYING ONLINE
  1. Create room (public or private), or Room search to find public rooms.
     Friends: invite them from the room (X), they accept on the main menu.
     Private room: share the room CODE (top of the room screen); your friend
     picks Room search > X Join with code.
  2. Sit at a table (A on a free seat). A on your own seat = READY.
     When both players at a table are READY, the fight starts after 3-2-1.
  3. After a fight: Rematch or Back to room. If either player picks Back to
     room, both go back. B stands up, hold B to leave the room.
  Both players need the same version of the mod.

UPDATES
  The launcher checks for a new version every time it opens and offers to
  install it (one click, a few seconds; your settings and My setup are kept,
  and nothing changes if it fails). The main menu also says so if a new
  version comes out while you play. (check=0 under [update] in rollback.ini
  turns the check off.)

PROBLEMS
  Help > Report a problem > Pack logs puts the logs in one zip on your Desktop
  (names and Steam IDs hidden). Attach it to a report on GitHub:
  https://github.com/robinneefs/million-arthur-arcana-blood-plus-r/issues

REMOVING THE MOD
  Installer version: Windows Settings > Apps > Arcana Blood +R > Uninstall.
  Zip version: delete the mod's folder, and dinput8.dll from the game's folder
  (if there is a dinput8.dll.before-plusr there, rename it back to dinput8.dll).
